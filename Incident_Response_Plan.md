# Incident Response Plan

## Phase 1: Detection

- Identify unusual file encryption
- Detect inaccessible files
- Verify backup availability

## Phase 2: Containment

- Disconnect affected systems
- Disable network access
- Preserve evidence

## Phase 3: Eradication

- Remove malicious software
- Scan endpoints
- Validate clean environment

## Phase 4: Recovery

- Restore data from backup
- Verify integrity
- Return systems to operation

## Phase 5: Lessons Learned

- Root cause analysis
- Recovery effectiveness review
- Security improvements
